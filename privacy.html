Your desktop stays yours.

Pictures and desktop interaction stay on your PC. Polar handles purchases, downloads and online licence checks. This page describes version 0.3.0.

Desktop icon positions

The app asks Windows' UI Automation provider for the on-screen bounds of desktop icons. Those coordinates make the bumps under the rug. The app does not read desktop files to create the bumps and does not move or delete them.

Settings and pictures

Preferences and a chosen custom picture are stored in %LOCALAPPDATA%\Kilim.Windows. The custom picture is resized and saved locally. Operation errors may be written to kilim.log in the same folder. The app has no usage analytics or built-in account registration; your Polar purchase supplies the licence key.

If you select Launch at sign-in, the app adds its executable path to the current user's Windows Run registry key. Turning off that setting removes the entry. It is off until selected.

Purchases and licence checks

The buy buttons open Polar's hosted checkout. Polar handles the checkout information, payment and delivery of your ZIP and key. Sign in to your Polar purchases with the purchase email to retrieve them or manage devices. Checkout and the customer portal are governed by Polar's own privacy information.

The Windows app contacts Polar to activate the key, validate it at every launch and every 30 minutes, and deactivate a device when requested. Requests include the key, public organization and licence-benefit identifiers, activation ID when applicable, and a hashed condition binding the PC and Windows user. The raw Windows machine GUID and user SID are not sent. Polar also receives normal connection information such as the request's IP address.

The key and activation ID are stored in activation.dat under the app's local folder, protected by Windows for the current user and bound to the device condition. They are not stored in preferences or included in licence error messages. Custom pictures, desktop icon coordinates and desktop file contents are not submitted for licence checking.

Runtime files

The self-contained executable extracts bundled native runtime files into the standard .NET temporary location when necessary. Those are runtime files, separate from your desktop documents and custom picture.

This website

The site code contains no analytics, advertising, contact forms, cookies or third-party JavaScript. The interactive preview and pattern selection run in your browser. No preview choice is sent to a server.

A public hosting or download service may retain normal request logs, including information needed to serve files. External links, including the upstream GitHub project, are governed by those services' own policies.

Removal

Turn off sign-in startup if enabled and deactivate this PC before deleting the app. You can also delete %LOCALAPPDATA%\Kilim.Windows to remove preferences, custom artwork, error logs and saved activation credentials. Deleting local files does not release Polar's activation slot or erase order records held by Polar. See the setup and removal guide.
