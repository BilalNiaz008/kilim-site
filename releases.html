Included in 0.1.0

  • A draggable, foldable cloth rug with roll/unroll and desktop-icon bumps.
  • Peek mode, with configurable Control, Shift or Alt key.
  • Fifteen rug patterns and a local custom-picture option.
  • Sizes, clock-based lighting, procedural sound and volume controls.
  • A shared rug across multiple monitors, with one desktop window per display.
  • Local preferences, optional launch at sign-in and tray controls.
  • A bundled .NET runtime and included upstream/runtime attribution.

What was checked

Model checks passed for contact, finite cloth positions, picking, dragging, roll/unroll, resize, monitor-origin translation, all rug images, custom weaving and audio generation. An extracted self-contained package launched with installed runtime lookup disabled.

Desktop integration was checked on one Windows PC with two monitors and 21 desktop icons. Its windows stayed above desktop icons and below the foreground app. This is the actual test scope, rather than a claim of compatibility with every Windows configuration.

Known limits

  • The executable is unsigned; Windows may show an unknown-publisher warning.
  • ARM64 hardware has not been tested.
  • The menus are English.
  • Preset rugs reuse upstream preview images. The original procedural painter and exact Metal shading are not ported.
  • A file picker provides custom pictures; tray drag-and-drop is not included.
  • Windows shell variations, mixed-DPI display changes and Show Desktop behaviour need more testing.

This is a portable beta, not an official Windows release from the original Kilim author. Read the credits and setup guide.
