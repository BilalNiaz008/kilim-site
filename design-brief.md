# Kilim for Windows — website design and launch brief

Help visitors understand the desktop rug, check Windows compatibility, and purchase the licensed 0.3.0 beta for US$1 once. The approved direction is **Linen and indigo**: a warm textile showroom with a playful Windows desktop scene.

Use linen #F5F0E6 for the page, deep ink #243650 for text, indigo #2D4772 for purchase actions, warm stone #E6DECE for the desktop stage and rosewood #A85C5B for small decorative details. Secondary text is #5F645F; paper surfaces are #FCF9F2. Use locally bundled Bricolage Grotesque for display headings and Segoe UI for body text.

The hero places a short, expressive headline and purchase action on the left, with a larger Windows desktop monitor on the right. Show a blue illustrated wallpaper, centered taskbar, Recycle Bin and a clustered mix of nine sample files. The rug covers that cluster physically while the files remain in place. Supporting pages use the same palette and typography. Keep the selected pattern large, distinguish the purchase panel in indigo, and retain the actual desktop video.

Motion belongs to the rug: show the clutter briefly before covering it once on page load, provide Replay cover, lift/tilt while dragging, settling on release, and brief preview/pattern transitions. Reduced-motion visitors see a covered still and can use Peek. Do not animate every section or add a full browser cloth simulation. Reuse the actual app renderings and label the browser interaction as a preview.

Sample files, folders and Recycle Bin stay fixed as a decorative Windows desktop scene. Keep rug dragging, Peek and Replay cover. There are no icon-movement or reset controls. The scene never accesses the visitor's real files.

The customer journey is **Buy for $1 → Polar checkout → ZIP and licence key → extract → run → activate**. Returning buyers use the suko-pro customer portal. Polar handles payment and protected file delivery. The website stays static, and its purchase links work without JavaScript.

State the one-PC and Windows-user activation limit before purchase. Internet is required at activation, every launch and checks every 30 minutes; failed checks close the rug. Explain how to deactivate and transfer a licence in setup and FAQ copy.

Keep the 0.3.0 version, ZIP size, checksum and source archive consistent. Never link a free app binary or preview package from the paid site. Preserve the MIT source download and Yusuf Yılmaz's original Kilim attribution. Describe this as an unofficial Windows adaptation, with an unsigned executable and untested ARM64 compatibility.

The privacy page must reflect Polar purchase and licence requests, the hashed device condition, Windows-protected local credentials, and local-only custom pictures and desktop interaction. Website Google Analytics uses measurement ID G-TPDNTJCHD7 and first-party cookies; disclose it alongside a link to Google's privacy information. Do not claim the site has no analytics or that the licensed app runs without network requests.

Verify the existing preview controls, all six pages at desktop/tablet/mobile widths, keyboard accessibility, the permanent checkout destination, the returning-buyer portal and publication contents. Preserve the kilimwindow.online CNAME. A live purchase/activation and device-transfer test remains a separate release check.
