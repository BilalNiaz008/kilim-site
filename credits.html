A rug with a story.

Kilim for Windows builds on an original macOS project and gives its cloth a different desktop to live on.

The original Kilim

Kilim by Yusuf Yılmaz introduced the desktop rug, cloth simulation and procedural artwork for macOS. Its source and artwork are available under the MIT licence.

The Windows adaptation is based on upstream commit 7fd785efd00900fa70af7288730c4a9029a18858. The C# cloth model adapts the original simulation and roll geometry. Preset rug textures reuse the project's preview artwork.

The Windows adaptation

This is an independently developed Windows beta. It uses WPF rendering, Windows desktop windows, UI Automation for icon positions, and local sound synthesis. It is not an official release or an endorsement from the original author.

Download Windows source

The editable 0.3.0 source includes the project, artwork attribution, licence activation, diagnostics and a script for rebuilding the self-contained Windows package. The packaged download is sold through Polar; the source remains available under MIT.

Images on this site

The rug-state images were generated by the Windows app's offscreen test renderer. The desktop backdrop is an illustration. The website preview moves images and changes states; the actual cloth physics runs in the Windows app. Gallery images show the built-in patterns.
