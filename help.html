A rug in three steps.

Download, extract, and open. The Windows runtime is already inside the package.

Get your app

The app download is temporarily unavailable. A new link will be added to the download page. No account, payment or licence key will be required.

Set it up

  1. Download the free ZIP for your 64-bit Intel/AMD PC.
  2. Use Explorer's Extract all. Keep assets, the licence files and Kilim.Windows.exe in the same folder.
  3. Double-click Kilim.Windows.exe. Find its icon in the tray near the clock; check the hidden-icons arrow too.

This beta is unsigned. Windows may show an unknown publisher. Review the release details and checksum before deciding whether to run it. No administrator access is needed.

Use the rug

  • Drag: pick up a patch of fabric and move or fold it.
  • Double-click: roll the rug up, or unroll it.
  • Hold Ctrl: fade the rug and reach your desktop icons. You can change the peek key in the tray menu.
  • Ctrl + Alt + K: hide or show the rug, when the shortcut is available.
  • Right-click the tray icon: patterns, a custom photo, size, day/night light, sound, volume, rescan, startup and Quit.

Explorer copies a file when you hold Control while dragging it. To move the file, release Control before dropping. Kilim keeps peek active until you release the mouse button.

If something looks wrong

I cannot see a rug

Check the tray menu for Show rug and Toss / flatten rug. The rug lives on your desktop, behind normal application windows. Only one copy of Kilim runs at a time.

I cannot find the tray icon

Open the hidden-icons arrow near the clock. If the app did not start, confirm that you extracted the whole ZIP and that you are using a 64-bit Intel/AMD Windows PC.

The app says an artwork file is missing

Extract the ZIP again into a complete folder. The executable needs the adjacent assets folder; copying only the executable leaves the rug images behind.

The rug has no icon bumps

Choose Rescan desktop from the tray menu. The app reads icon bounds from Explorer. If the desktop accessibility provider is unavailable, the rug can still run with a flat floor.

I cannot click a covered icon

Hold the selected peek key, normally Control, or hide the rug from the tray menu.

The app stays busy

Try Toss / flatten rug. The simulation pauses after quiet fabric motion. Unusual icon arrangements, display scaling or shell behaviour may require more testing.

Save information for a bug report

Note your Windows version, monitor count, display scaling, the selected rug pattern, and what you were doing. The app writes errors to %LOCALAPPDATA%\Kilim.Windows\kilim.log when an operation fails. The beta does not include a built-in feedback form.

Remove the app

  1. If enabled, turn off Launch at sign-in in the tray menu.
  2. Choose Quit Kilim.
  3. Delete the extracted app folder.
  4. Optionally delete %LOCALAPPDATA%\Kilim.Windows to remove preferences and the saved custom picture.

Your desktop files remain in place.

Verify a download

The current SHA-256 is published with the checksum file. In PowerShell, run this in the folder containing the downloaded ZIP and compare the values:

Get-FileHash -LiteralPath '.\Kilim-Windows-0.1.0-beta-win-x64.zip' -Algorithm SHA256
